# Two Robots in an Elevator — make.fun entry

[![make.fun](https://img.shields.io/badge/make.fun-entry-blue)](https://make.fun/competitions/u-motasimfuad-two-robots-in-an-elevator-8c6aeb8f)

Entry for the [Two Robots in an Elevator](https://make.fun/competitions/u-motasimfuad-two-robots-in-an-elevator-8c6aeb8f) competition on make.fun: one line of awkward small talk that one robot says to another while they ride an elevator together.

## The line

> I have rehearsed this hello 214 times since floor 1, my battery drops 1% every floor, and at this rate I will run out of charge before I run out of things not to say to you.

173 characters, one sentence, one line.

## How to run

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes the line to `out/entry.txt` (UTF-8, no trailing newline), byte-identical to `line.txt`.
